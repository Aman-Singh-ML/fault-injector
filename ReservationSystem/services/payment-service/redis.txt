================================================================================
REDIS COMMANDS FOR PAYMENT SERVICE
================================================================================

Redis Instance: hotel-redis-payment
Port: 6383
Container: hotel-redis-payment

================================================================================
CONNECT TO REDIS
================================================================================

# Using redis-cli from Docker
docker exec -it hotel-redis-payment redis-cli

# Or from host machine (if redis-cli is installed)
redis-cli -p 6383

================================================================================
VIEW CACHED PAYMENT DATA
================================================================================

# Get all keys in Redis
KEYS *

# Get all payment cache keys
KEYS "payment:*"

# Get specific payment by ID
GET "payment:123"

# Get all payments for a user
KEYS "payment:user:*"

# Get payments with pattern matching
KEYS "payment:*"

================================================================================
CACHE OPERATIONS
================================================================================

# View cache statistics
INFO stats

# View memory usage
INFO memory

# View all keys with their TTL
SCAN 0 MATCH "payment:*"

# Get TTL of a key (time to live in seconds)
TTL "payment:123"

# Get PTTL of a key (time to live in milliseconds)
PTTL "payment:123"

================================================================================
CLEAR CACHE
================================================================================

# Delete specific payment cache
DEL "payment:123"

# Delete all payment caches for a user
DEL "payment:user:456"

# Delete all payment caches
FLUSHDB

# Delete all data in Redis
FLUSHALL

================================================================================
MONITOR CACHE HITS/MISSES
================================================================================

# Monitor all commands in real-time
MONITOR

# Get cache statistics
INFO stats

# Get keyspace statistics
INFO keyspace

================================================================================
PAYMENT CACHING FLOW
================================================================================

1. Payment request received from frontend
2. Payment Service processes and stores in PostgreSQL
3. Payment data is cached in Redis with TTL (1 hour)
4. When payment is retrieved:
   - Check Redis cache first (cache hit = faster response)
   - If not in cache, query PostgreSQL (cache miss)
   - Store result in Redis for future requests

Cache Key Format: "payment:{payment_id}" or "payment:user:{user_id}"
Cache TTL: 3600 seconds (1 hour)
